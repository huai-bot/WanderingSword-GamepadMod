# 更新记录

## v4.22（2026-11-24）
- 修正 Start 打开武学的问题：人物栏目编号从 0 开始，改为打开 0（队伍），并确认背包显示后才应答成功
- 新增每 120 秒自动存档：按现实时间计时，调用游戏原有 `SaveManager:AutoSave()`；战斗、对话、菜单、加载或角色未落地时延后，恢复安全后再请求存档
- 传送列表按拼音字母排序，保留各区域分页；未到访地点显示灰色「未解锁」，手柄、回车和鼠标均不能向其传送
- 修复手柄 Y 无法触发速战：代理直接接收战斗中的 Y 单键，与鼠标加速按钮共用 1 倍 → 2 倍 → 速战 → 1 倍循环；LB+Y / RB+Y 保持游戏原有功能，Lua 停止更新 500 ms 后恢复原生 Y

## v4.21（2026-11-24）
- 修复 Start 偶尔打开任务等栏目：明确打开人物界面的「队伍」栏目，不再沿用上次的栏目；正常打开、关闭不发送键盘事件，保留当前输入模式
- 修复速战触发不稳定：直接识别游戏的加速按钮事件，不再把图标刷新当作按键；开场按键进入正常循环，模组自己修正图标不会重复切换倍率
- 速战默认临时静音本游戏，退出速战、结算和超时回退后恢复原来的静音状态，不影响其他应用或游戏音量设置；新增 `quick_mute`（默认 1），独立于画面遮罩
- 安装时默认关闭 UE4SS 控制台和图形日志窗口，保留文件日志；游戏运行中拒绝安装，备份统一放在 `D:\TOOLS\dshdata\dshbackup\`，可复用已有备份
- 合并此前未提交更新：Start 打开人物界面；速战画面遮罩（`quick_mask`，默认 1）；后台切磋验证与 Lua 重载工具
- 原生静音和遮罩都有 500 ms 超时保护，Lua 停止更新时自动解除；需更新 DLL 并重启游戏

## v4.15（2026-11-23）
- 新增**速战**：战斗加速按钮改为 1 倍 → 2 倍 → 速战 → 1 倍 循环（去掉 3、4 倍）。速战 = 游戏自带自动战斗 + 时间流速 50 倍，战斗仍由游戏完整模拟，胜负照常结算；结算画面出现即恢复正常速度。自动战斗由速战打开的，离开速战后会自动关掉（下一场非速战战斗也会关）
- 速战超过 `quick_timeout`（默认 90 秒）还没分出胜负，自动退回 2 倍速（自动战斗保持开启）
- 速战期间右上角加速图标上显示「速战」标记（新 `xinput1_3.dll`）
- `wsmod.ini`：去掉 `speed_max`，新增 `quick_battle` / `quick_speed` / `quick_timeout`
- 实测（1v1 切磋，同一对手）：3 倍 36 秒、20 倍 8 秒、50 倍 6 秒、100 倍 5 秒；倍率再高收益很小（动画和回合交接是按帧算的）
- 修复：战斗里技能特写会隐藏战斗界面，之前此时不再维持倍率；同时存在上一场残留的战斗界面时可能读错加速图标

## v4.14（2026-11-23）
- 观察界面（与 NPC 交互 → 观察）手柄跳过「属性」「装备」：打开时焦点直接在第一个底部按钮（切磋），LT/RT 在背包和底部按钮之间切换，底部按钮按上进入背包，背包最左列再往左不再跳到装备栏；切回时回到原来的背包格子和按钮
- 「全部」分类也隐藏游戏标了「学成」的秘籍（格子数据 `is_acquired`；与当前角色是否学会无关），只在「秘籍」分类显示。见过的书记在 `acquired_books.txt`，之后打开直接隐藏不闪
- 人物界面切回头像栏时稳定回到原来的头像（直接聚焦该头像，不再经过 `ChangeNaviFocus("SideBar")`，后者会在约 0.5 秒后把焦点拉回主角）
- 手柄输入过滤在键鼠模式下也生效（键鼠模式下第一下摇杆会同时切换模式并移动焦点）
