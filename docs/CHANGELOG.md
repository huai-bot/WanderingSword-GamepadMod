# 更新记录

## v4.12（2026-11-23）
- 人物界面切区不再闪烁：会走进「属性」「装备」的输入（任意位置的 LT/RT、头像栏的右、底部按钮的上，十字键和左摇杆都算）在 `xinput1_3.dll` 里直接拦下，交给 Lua 跳转；背包最左列再往左时，游戏自己发出的 `ChangeNaviFocus("Equip")` 被改写成头像栏。焦点全程不经过这两栏
- 切回头像栏时回到原来选中的头像，切回背包时回到上次停留的格子
- **需要新的 `xinput1_3.dll`，更新后重启一次游戏**（旧 DLL 下只拦截 LT/RT，十字键/左摇杆仍会闪一下）

## v4.10（2026-11-23）
- 人物界面手柄跳过「属性」「装备」两栏：LT/RT 改为在 头像 → 背包 → 底部按钮（上阵/坐骑/切磋/送礼…）之间循环，方向键走进这两栏时自动弹到另一侧；鼠标（右摇杆指针）不受影响。新增 `prime_skip_panels` 开关
- 修复：在大地图（行走地图）上打开人物界面时背包的排序、隐藏和高亮不生效。大地图上 `battle.flag` 也是 1，背包功能改为只在真正战斗时停用

## v4.9（2026-11-23）
- 修复：v4.6–v4.8 判断当前分类用的是标签按钮的 `bIsActive`，它始终停在「全部」，导致已学成秘籍、任务道具、材料在各自分类里也被隐藏。改用背包 VM 的 `GetFilterIndex()`，各自分类恢复正常显示
- 「全部」分类也隐藏珍宝（`EItemSubType` 50–56：书画、棋具、茶具、古籍、琴、珍宝、花），只在「珍宝」分类显示

## v4.8（2026-11-23）
- 「全部」分类也隐藏烹饪/锻造/缝制等材料（`EItemSubType` 40–49），只在「材料」分类显示
- 切换角色/分类不再闪烁：打开人物界面时为所有队员一次性算好隐藏表并缓存；在游戏生成格子时（`BP_ItemGridWDT_C:BP_OnEntryInitialized_Event_0` 钩子）就把要隐藏的格子设为透明，随后移出列表；由模组触发的重建在同一帧内过滤完
- 队友按武器类型预判不可用的武器和武学秘籍；游戏置灰过的物品记入缓存，下次直接隐藏
- 调度循环改为 20 ms 一拍（`every` 单位相应调整）；新增 `cell_hook` 开关

## v4.7（2026-11-23）
- 「全部」分类里隐藏：当前角色已学成的秘籍、已学成的烹饪/锻造/缝制图纸、任务道具；它们仍显示在各自分类里（`tidy_all_tab`）

## v4.6（2026-11-23）
- 隐藏不可用物品改用游戏自己的判定：被游戏置灰（`not_learnable`）的武器、秘籍等一律隐藏，切换角色或分类后自动重新隐藏
- 背包任务频率提高到 200 ms，切换时闪现更短

## v4.5（2026-11-23）
- 修复装备高亮误判：属性 = 物品表基础属性 + 该件装备的随机加成（与游戏提示框数值一致），之前只比较了随机加成
- 去掉按对象地址缓存属性（列表重建后地址会被新物品复用，导致张冠李戴）；不再符合条件的格子会自动清除颜色
- 默认高亮色改为更深更蓝的 `5C6CFF`

## v4.4（2026-11-23）
- 修复传送掉到地图下方：传送只调用 `ChangeSceneMap`（之前再调 `StartChangeMap` 导致地图加载两次）
- 到访点改为「最近一次站在地面上的位置」（落地 2 秒后记录，最多 20 秒刷新一次），不再记录刚载入时的临时位置
- 读取时丢弃坐标完全相同的可疑到访点
- 传送落地保护：到达后 25 秒内若角色下坠超过 2.5 秒、低于目标 1500 或角色消失，自动送到该地图的 PlayerStart
